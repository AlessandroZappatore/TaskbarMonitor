Frequently asked questions

Can't find your answer? Open an issue on GitHub.

Why does Windows show a SmartScreen warning?

The executable is not code-signed, because code-signing certificates cost money and this is a free hobby project. Windows warns about any unsigned program that few people have downloaded. Click More info, then Run anyway.

If you would rather not run a downloaded file, the program is a few small, readable source files. Build it yourself with build.bat, using the compiler included with Windows.

Does Taskbar Monitor connect to the internet?

No. It makes no network connections, has no telemetry and no accounts. It only reads local counters and stores its settings in the registry under HKEY_CURRENT_USER\Software\TaskbarMonitor.

Why is the temperature different from HWiNFO or other tools?

Taskbar Monitor shows the thermal zone temperature that Windows reports through ACPI. It is a system-level value, not a per-core reading. Exact per-core temperatures need a kernel driver and administrator rights, which this app avoids on purpose. If your PC does not expose a thermal zone, the widget shows two dashes.

How do I hide the widgets and bring them back?

Right-click a widget and choose Hide widgets. To show them again, use any of these:

  • Click the Taskbar Monitor icon in the notification area.
  • Press Ctrl + Alt + M.
  • Open TaskbarMonitor.exe again.
  • Right-click the tray icon and choose Show widgets.

The tray icon may be inside the ^ menu next to the clock. Drag it onto the taskbar to keep it always visible.

Can I choose what the widget shows?

Yes. Right-click a widget and choose Settings. The stats widget has six positions in three columns of two. For each one you can pick download speed, upload speed, CPU usage, CPU temperature, RAM usage or used GB, disk activity, disk read or write speed, free space on the system drive, GPU usage, battery or PC uptime, or leave it empty. Changes apply immediately and empty columns disappear, so the widget only takes the space it needs.

Why does the GPU or temperature show two dashes?

Two dashes mean Windows does not expose that value on your PC through the counters Taskbar Monitor uses. GPU usage relies on the GPU Engine performance counters, which need a recent graphics driver. Temperature relies on an ACPI thermal zone. Battery also shows two dashes on a PC without a battery.

Which players does the now-playing widget support?

Any app that uses the Windows media controls: Spotify, YouTube and other sites in Chrome or Edge, VLC and many others. If a track shows up in the Windows volume flyout, it will show up in the widget. Cover art depends on what the app provides.

Does it work on Windows 10?

It is developed and tested on Windows 11. Windows 10 version 1809 or newer provides all the APIs it needs, so it should work, but it is less tested. Please open an issue if something looks wrong.

Does it support several monitors or a taskbar that is not at the bottom?

It is designed for a taskbar at the bottom of the primary monitor. You can drag the stats widget to another position, but the default placement and the now-playing widget assume the bottom taskbar.

A widget covers something on my taskbar. What can I do?

Drag the stats widget to a free spot. The now-playing widget sits at the far left and can cover the Widgets button; turn it off with Show now playing in the menu if that bothers you.

How do I make it start with Windows?

Right-click a widget and turn on Start with Windows. If you later move the executable, turn the option off and on again so the startup entry points to the new location.

How do I uninstall it?

Turn off Start with Windows, choose Exit from the menu and delete TaskbarMonitor.exe. Optionally delete the registry key HKEY_CURRENT_USER\Software\TaskbarMonitor. Nothing else is installed.
